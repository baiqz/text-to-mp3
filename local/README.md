# 文字转 MP3（不限长度）

把**任意长度的文字**转成一个 MP3 文件。粘贴几万字、拖进一整本书的稿子都不会被截断——
程序自动按句子切块、并发合成、再按原顺序拼回一个音频。

本地运行，基于 Python + Flask + edge-tts（微软 Edge 神经语音引擎，音质接近真人）。

## 先说清楚"不限长度"是怎么做到的

绝大多数在线 TTS 工具都有字数上限，因为语音接口单次请求的文本量有限制，
长文本要么被截断，要么直接报错。这里的做法是：

```
长文本 ──▶ 智能切分 ──▶ 并发合成(每段独立重试) ──▶ 帧级拼接 ──▶ 单个 MP3
             │                    │                      │
        永不切断句子        失败不拖垮整体        丢弃残缺帧，保证结构合法
```

三段关键处理：

1. **切分**：按 `段落 → 句末标点 → 停顿标点 → 空格 → 硬切` 逐级递降，
   保证每一块都停在语义边界上。在句子中间断开会让语音语调直接"摔在地上"。
2. **合成**：每块独立请求、独立重试（3 次指数退避），一块失败不影响其他块（可配置为严格模式）。
   合成完一段就落盘一段，内存占用与文本长度无关。
3. **拼接**：MP3 不是随便拼字节就能用的。这里做了帧级处理——
   跳过 ID3 标签、逐帧按帧长前进、丢弃结尾残帧，只输出干净的连续帧流。
   实测拼接后时长与各段之和**误差为 0**。

## 快速开始

双击 `start.bat`，浏览器会自动打开 <http://127.0.0.1:5300>。

或者手动：

```bash
python app.py            # 启动后自动开浏览器
python app.py --no-browser
python app.py --reuse    # 复用已在运行的实例，不重启
```

服务只监听 `127.0.0.1`，不对外网开放。端口被占用时会自动往后找。

**关于"双击 start.bat 没反应"**：如果检测到已有实例在跑，2.1 之前会静默打开旧界面就退出，
看起来就像没反应——而那个旧实例往往正是问题源头（它可能带着过期的网络设置）。
现在遇到这种情况会**明确提示并自动关闭旧实例、启动新实例**，控制台会打印：

```
检测到已在运行的服务实例（端口 5300）
正在关闭它并启动新实例……
旧实例已退出。
```

想复用旧实例（不打断正在进行的转换）就用 `start.bat --reuse`。
想彻底关掉服务，双击 `停止.bat`。

## 界面怎么用

| 区域 | 说明 |
| --- | --- |
| 文本框 | 直接粘贴任意长度文字；也可拖入 `.txt / .md / .docx / .csv / .srt / .html` 文件 |
| 实时统计 | 字数、预估朗读时长、将要分成几块 |
| 音色 | 37 个精选中英文音色；切到「全部语音」可搜索全部 331 个（含各种小语种） |
| 语速/音量/音调 | 语速 −50% ~ +100%，音量与音调 ±50 |
| 高级设置 | 文件名、分块字符数、并发数、Markdown 清理、部分失败仍输出 |
| 转换进度 | 实时显示第几段 / 共几段、已生成音频时长、已用时间，随时可取消 |
| 结果 | 在线试听（可拖进度条）+ 下载 MP3；文件同时保存在 `outputs/` |
| 历史 | 右侧抽屉列出所有生成过的文件，可试听、下载、删除 |
| 右上角引擎状态 | **点它可以随时跑一次网络诊断**，报告直接显示在文本框下方 |

## 转不出来的时候怎么办

失败信息现在会带上**真实原因**，不再只说"请检查网络"。三种自查方式，由简到繁：

**1. 看报错本身。** 转换失败时界面会列出真实异常，例如
`SSLError: ...` / `ConnectionRefusedError: ...` / `403 Forbidden`，
并附一句网络诊断结论。

**2. 点右上角引擎状态**，会当场跑一次完整诊断并把报告显示出来。

**3. 双击 `诊断.bat`**（不依赖服务是否在跑），输出一份分层报告：

```
【运行环境】  Python / edge-tts 版本、环境代理、系统代理
【网络连通】  域名解析 → TCP 443 → 直连 HTTPS → 各条代理
【语音合成】  真实试合成一小段音频
【结论/建议】 卡在哪一层，下一步做什么
```

报告同时保存到 `logs/diagnose_*.txt`，出问题可以直接把内容贴出来。

### 两种最容易踩的坑

**旧实例带着失效的网络设置。** 服务进程如果是在某个终端 / 启动器里启动的，
会继承当时的 `HTTP_PROXY` 环境变量。那个代理一旦退出，进程里每次请求都会先撞死代理，
现象和彻底断网一模一样。程序现在做两件事防它：

- **启动时**先探测环境代理是否真的可用，失效的直接从进程环境里摘掉；
- **整批失败时**自动换通路重试（直连 ↔ 环境代理 ↔ 系统代理），而不是原地报错。

**edge-tts 版本过旧。** 微软会更新客户端校验，旧版本会返回 403。升级即可：

```bash
pip install -U edge-tts
```

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查（含 PID 与引擎版本） |
| GET | `/api/voices` | 音色清单（精选 + 全量） |
| POST | `/api/analyze` | 文本统计：字数、预估时长、分块数 |
| POST | `/api/tts` | 创建转换任务 |
| GET | `/api/jobs/<id>` | 任务状态快照（含真实错误样本、所用通路） |
| GET | `/api/jobs/<id>/events` | 进度流（SSE） |
| GET | `/api/jobs/<id>/audio` | 在线试听（支持 Range） |
| GET | `/api/jobs/<id>/download` | 下载 MP3 |
| POST | `/api/jobs/<id>/cancel` | 取消任务 |
| GET | `/api/history` | 历史生成记录 |
| DELETE | `/api/history/<name>` | 删除历史文件 |
| POST | `/api/extract` | 上传文件抽取文字 |
| GET | `/api/selftest` | 引擎自检（真合成一小段，自带换通路） |
| GET | `/api/diagnose` | 完整网络诊断；加 `?format=text` 返回可读报告 |
| POST | `/api/shutdown` | 让本实例退出（供 start.bat 接管旧实例用） |

`POST /api/tts` 请求体：

```json
{
  "text": "任意长度文字",
  "voice": "zh-CN-XiaoxiaoNeural",
  "rate": 0, "volume": 0, "pitch": 0,
  "title": "文件名(可空,默认取首句)",
  "chunk_chars": 1200,
  "concurrency": 3,
  "strip_markdown": true,
  "keep_partial": true
}
```

## 其他常见问题

**为什么有时一块里有换行、有时没有**
块是独立合成的单元，首尾空白会被去掉；块内部保留段落换行，避免两段连读成一句。

**输出的 MP3 能直接用在哪些地方**
24kHz / 48kbps / 单声道，带 ID3 标题。浏览器、微信、剪映、各类剪辑与播放器都识别。
时长超过 20 分钟的单文件已实测无问题。
